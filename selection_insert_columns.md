# PPAT-018 Selection Insert Data (selection_experiment_insert_data) — Column Guide

- **`bc_sequence`**: Corrected barcode sequence.
- **`bc_length`**: Length of the barcode sequence (observed range ~42-46 bp).
- **`reference_name`**: Reference sequence/genome name the insert aligned to.
- **`reference_start`**: 0-based start position of the aligned insert on the reference.
- **`reference_end`**: End position of the aligned insert on the reference.
- **`mapping_quality`**: MAPQ alignment score, taken from a representative read for the barcode.
- **`is_reverse`**: Whether the genomic fragment's reverse strand faces the synthetic promoter (True) vs. the forward/+ strand (False) -- determines sense/antisense orientation for any gene the fragment covers.
- **`insert_sequence`**: Insert DNA sequence, taken from a representative read for the barcode.
- **`insert_alignment_start`**: Start position of the aligned insert within the read (query_alignment_start).
- **`insert_alignment_end`**: End position of the aligned insert within the read (query_alignment_end).
- **`insert_type`**: Alignment/insert classification. Null values are filled with 'unknown'; observed values include 'aligned', 'empty_insert', 'unknown'.
- **`aligned_length`**: Length of the aligned insert (insert_alignment_end - insert_alignment_start).
- **`library_sample`**: Sample/run identifier (folder name) the long-read library data came from; for barcodes seen across multiple runs, this is the run names joined with '_'.
- **`n_reads`**: Number of PacBio reads supporting this barcode.
- **`mean_raw_read_length`**: Mean raw PacBio read length across reads supporting this barcode.
- **`median_raw_read_length`**: Median raw PacBio read length across reads supporting this barcode.
- **`min_aligned_length`**: Minimum aligned_length across PacBio reads supporting this barcode.
- **`max_aligned_length`**: Maximum aligned_length across PacBio reads supporting this barcode.
- **`species_short`**: Short species name matched to this sample from the species tracking grid (NaN if no match found).
- **`species_full`**: Full genome path matched to this sample from the species tracking grid (NaN if no match found).
- **`sample_x`**: Sample identifier from the long-read library side of the final merge (derived by stripping the species suffix off library_sample).
- **`overlapping_features`**: All genes touching the fragment, by full or partial overlap.
- **`coverage_type`**: Categorical label describing how genes are covered by this fragment (e.g. 'Single Gene (Full) [Plus Strand]').
- **`fully_covered_genes`**: Genes 100% contained within the fragment's boundaries.
- **`gene_ids_fully_covered`**: Gene IDs (any strand) that this fragment fully covers -- a gene is considered 'captured' in the design matrix if at least one fragment fully covers it.
- **`plus_strand_genes`**: Count of + strand genes among the fragment's overlapping features.
- **`minus_strand_genes`**: Count of - strand genes among the fragment's overlapping features.
- **`sense_genes`**: Fully covered genes in sense orientation relative to the synthetic promoter (requires is_reverse).
- **`antisense_genes`**: Fully covered genes in antisense orientation relative to the synthetic promoter (requires is_reverse).
- **`sense_count`**: Count of sense_genes (None if is_reverse wasn't available).
- **`antisense_count`**: Count of antisense_genes (None if is_reverse wasn't available).
- **`orientation_summary`**: Human-readable orientation summary (e.g. 'All Sense (2 genes)' or 'Mixed Orientation (Sense: 1, Antisense: 2)').
- **`library`**: Library identifier.
- **`environment`**: Selection environment/condition.
- **`replicate`**: Replicate identifier.
- **`timepoint`**: Sequencing timepoint (T0 or T1); this dataset is filtered to timepoint == 1 (T1) only.
- **`N`**: Total sequencing depth for the sample (short-read barcode count total).
- **`total_n`**: Total read count, summed across corrected barcodes mapping to this bc_sequence.
- **`total_freq`**: Total frequency, summed across corrected barcodes mapping to this bc_sequence.
- **`total_bl_freq`**: Total baseline frequency, summed across corrected barcodes mapping to this bc_sequence.
- **`n`**: Read count for this corrected barcode in the selection sample (pre-aggregation column; becomes total_n after integration).
- **`freq`**: List of short-read frequency values, one per uncorrected barcode contributing to this corrected bc_sequence.
- **`bl_freq`**: List of baseline-sample frequency values, one per uncorrected barcode contributing to this corrected bc_sequence.
- **`uncorrected_bc`**: Original pre-correction short-read (SR) barcode sequence for each sample (list column, length 1 here).
- **`ngs_correction_status`**: NGS barcode correction status per sample (list column, length 1 here); collapsed into the scalar correction_status column.
- **`N0`**: Baseline sample sequencing depth, used in the pseudofrequency correction.
- **`psi_freq`**: Pseudofrequency for depth correction: 1/sqrt(N0*N) (from the Boba-seq paper), added to both freq and baseline_freq before taking the fitness log-ratio.
- **`fitness`**: Barcode-level fitness score: log2(freq + psi_freq) - log2(baseline_freq + psi_freq).
- **`base_library`**: Base library ID, used to look up the corresponding long-read library data for this barcode.
- **`well`**: Well identifier in selection experiment.
- **`plate`**: Plate identifier in selection experiment.
- **`sample_y`**: Sample identifier from the metadata-CSV side of the final merge ('sample identifier matching short read directory names').
- **`construct`**: Name/identifier of the plasmid construct carrying this barcode, propagated from the sample sheet's 'construct' field (a SnapGene .dna file with barcode flanking regions annotated) -- inferred from long-read-qc/short-read-pipeline sample-sheet docs, not documented as a dataframe column directly.
- **`sense_gene_ids`**: Subset of gene_ids_fully_covered where the fragment is in sense orientation relative to the synthetic promoter.
- **`antisense_gene_ids`**: Subset of gene_ids_fully_covered where the fragment is in antisense orientation relative to the synthetic promoter.
- **`n_reps`**: Number of replicates in which this barcode was observed; the dataset is filtered to n_reps >= 2.
